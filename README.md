# Прогнозирование кредитного дефолта (Кредитный скоринг)

## Описание задачи
Бинарная классификация: предсказать, будет ли у заемщика просрочка 90+ дней в ближайшие 2 года.

## Стек
Python, Pandas, Scikit-learn, Matplotlib, Seaborn.

## Что сделано
1. Проведен разведочный анализ данных (EDA), выявлен дисбаланс классов (93% / 7%).
2. Очищены данные, обработаны пропуски и выбросы.
3. Обучено 10 моделей (LogReg, KNN, Decision Tree, Random Forest, Gradient Boosting, XGBoost).
4. Проведен подбор гиперпараметров (GridSearchCV).
5. Лучший результат показал ансамбль (Ensemble) из Random Forest и Gradient Boosting: **ROC-AUC = 0.937**.
6. Проанализирована важность признаков (Feature Importance) — главные факторы: доход, возраст, история просрочек.
